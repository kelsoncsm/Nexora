# F4 — Platform Administration

## Objetivo
Criar o painel e APIs de administração da plataforma.

Leia `MASTER_PLAN.md` e inspecione o projeto.

## Backend
Criar escopo seguro de Platform Admin.

Funcionalidades:
- listar tenants;
- visualizar tenant;
- ativar/desativar tenant;
- consultar usuários;
- gerenciar segmentos;
- dashboard básico;
- auditoria das ações administrativas.

## Segurança
Platform Admin e Tenant Admin são escopos diferentes.
Não permitir que um Tenant Admin execute endpoints de plataforma.

## Frontend
Criar área:
`/admin`

Menus:
- Dashboard
- Tenants
- Users
- Segments
- Audit Logs

Implementar guards e controle de acesso.

## Testes
- Platform Admin acessa.
- Tenant Admin não acessa.
- Usuário comum não acessa.
- Operações administrativas geram auditoria.
- Isolamento de tenant permanece intacto.

## Critérios de aceite
Painel administrativo funcional e protegido.

Não implementar planos, billing ou pagamentos nesta fase.
