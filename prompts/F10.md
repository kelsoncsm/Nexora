# F10 — Payments

## Objetivo
Integrar o primeiro gateway de pagamento de maneira desacoplada e segura.

Leia `MASTER_PLAN.md`.

## Arquitetura
Criar:
`IPaymentGateway`

Implementar somente o gateway definido para o MVP.

## Funcionalidades
- checkout;
- criação de cobrança;
- consulta de pagamento;
- webhook;
- atualização de assinatura;
- idempotência;
- logs sem dados sensíveis.

## Webhooks
Devem:
- validar autenticidade conforme gateway;
- ser idempotentes;
- suportar reprocessamento seguro;
- registrar eventos relevantes.

## Segurança
Nunca confiar somente no redirect do navegador para confirmar pagamento.

A confirmação deve vir de mecanismo server-to-server confiável.

## Testes
- pagamento aprovado;
- pagamento recusado;
- webhook duplicado;
- webhook fora de ordem quando aplicável;
- assinatura atualizada;
- falha de gateway.

Não integrar múltiplos gateways.
