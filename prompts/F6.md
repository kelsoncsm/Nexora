# F6 — Customers

## Objetivo
Implementar o módulo de clientes tenant-scoped.

Leia `MASTER_PLAN.md`.

## Entidade
Customer:
- Id
- TenantId
- Name
- Phone
- Email
- BirthDate
- Notes
- Status
- CreatedAt
- UpdatedAt

## Backend
Implementar:
- CRUD;
- busca;
- paginação;
- filtros;
- ordenação;
- validação.

Usar DTOs e contratos de API.

## Segurança
Toda operação deve respeitar TenantId e autorização.

## Frontend
Criar:
- lista;
- busca;
- cadastro;
- edição;
- visualização;
- exclusão conforme permissão.

## Testes
- CRUD;
- validação;
- paginação;
- isolamento entre tenants;
- permissões.

## Critérios de aceite
Tenant A nunca consegue consultar ou alterar clientes do Tenant B.
