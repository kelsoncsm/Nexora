# F5 — Plans e Features

## Objetivo
Criar sistema configurável de planos, funcionalidades e limites.

Leia `MASTER_PLAN.md`.

## Entidades
Criar/adaptar:
- Feature
- Plan
- PlanFeature
- TenantFeatureOverride

## Funcionalidades
Platform Admin deve conseguir:
- criar plano;
- editar plano;
- ativar/desativar plano;
- cadastrar feature;
- associar feature ao plano;
- configurar limites;
- configurar override por tenant quando previsto.

## Resolução
Criar serviço equivalente a:
`IFeatureAccessService`

Ele deve resolver se um tenant possui determinada feature e qual seu limite.

## Regras
Não hardcodar:
- nomes de planos;
- preços;
- limites;
- features.

## Frontend
Criar telas administrativas de:
- Features;
- Plans;
- configuração de PlanFeature.

## Testes
- feature habilitada;
- feature desabilitada;
- limite;
- override;
- tenant sem feature;
- plano alterado;
- autorização administrativa.

## Critérios de aceite
O acesso às funcionalidades pode ser alterado pelo Platform Admin sem alteração de código.

Não implementar billing de assinatura ainda.
