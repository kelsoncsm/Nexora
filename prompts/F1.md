# F1 — Fundação Técnica

## Objetivo
Criar a fundação executável do Nexora.

## Pré-requisito
F0 concluída e documentação disponível.

Leia `MASTER_PLAN.md` e inspecione o repositório antes de editar.

## Tarefas Backend
- Criar solução/projetos .NET conforme arquitetura definida.
- Configurar ASP.NET Core.
- Configurar PostgreSQL + EF Core.
- Configurar OpenAPI/Swagger.
- Configurar logging estruturado.
- Configurar tratamento global de exceções.
- Criar health checks.
- Criar configuração por ambiente.
- Criar estrutura inicial para testes.

## Tarefas Frontend
- Criar aplicação Angular.
- Configurar ambiente de desenvolvimento.
- Configurar routing base.
- Criar estrutura inicial para autenticação futura.
- Criar layout mínimo sem implementar módulos de negócio.

## Infra
- Criar Dockerfile(s) necessários.
- Criar `docker-compose.yml`.
- Configurar PostgreSQL local.
- Garantir que serviços iniciem de forma previsível.

## Testes
- Teste de inicialização da API.
- Teste de health check.
- Teste de conexão com banco, quando aplicável.
- Build frontend.
- Build backend.

## Restrições
Não implementar:
- login;
- tenancy;
- billing;
- agenda;
- clientes;
- pagamentos.

## Critérios de aceite
- Backend inicia.
- Frontend inicia.
- PostgreSQL inicia.
- Swagger funciona.
- Health check funciona.
- Testes base passam.
- Docker Compose funciona.

Finalize com arquivos alterados, comandos executados, testes e pendências. Não avance para F2.
